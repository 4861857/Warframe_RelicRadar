# 虚空裂缝报酬 自动估价

由于本人最近在瘾星际战甲，因此为了解决自己的痛点，帮助萌新快速识别遗物道具的稀有性，就用AI做了这个工具，亲测可用，但有时候因为网络问题，可能会超出15s的道具选择时间，但，有比没有好，不是吗。

在《星际战甲》(Warframe) 虚空裂缝结算界面，按一个热键，自动截图 → OCR 识别道具 → 从 [warframe.market](https://warframe.market/zh-hans/) 抓取价格 → 弹窗显示，并标注每个道具的**入库 / 出库**状态。

## 安装

需要 Python 3.10+（本项目在 3.14 上验证通过）。

```bash
pip install -r requirements.txt
```

## 使用

```bash
python wf_price_tool.py
```

程序启动后：
1. 首次运行自动下载并缓存两份数据：道具名单（`item_names.json`）和遗物掉落表（`relic_drops.json`）。
2. 出现一个置顶小窗，显示“就绪”。
3. 把游戏停留在**虚空裂缝报酬结算界面**，按 **F9**（默认），窗口即更新。

### 其它命令

```bash
python wf_price_tool.py --image 某张截图.png   # 识别一张图片后打印结果（不弹窗）
python wf_price_tool.py --refresh             # 重新下载两份缓存
```

## 入库 / 出库说明

每个道具右下角会有一个标签：

| 标签 | 含义 |
|------|------|
| **已入库**（橙） | 该道具的所有来源遗物均已入库，暂时无法掉落，价格通常更高 |
| **出库中**（绿） | 至少有一个来源遗物仍可掉落（当前可刷） |
| 未知（灰） | 无来源遗物数据（非遗物掉落物） |

判定逻辑：道具若出现在**任意一个当前未入库的遗物**中，即视为“出库中”；仅当所有来源遗物都已入库才是“已入库”。

数据来源：
- 道具 ↔ 遗物映射：DE 官方掉落表的社区镜像 [WFCD/warframe-drop-data](https://github.com/WFCD/warframe-drop-data)（自动更新）。
- 遗物是否入库：warframe.market 实时数据。

## 配置

打开 `wf_price_tool.py`，顶部有一段配置：

| 配置 | 默认 | 说明 |
|------|------|------|
| `HOTKEY` | `"f9"` | 触发热键。单键用 `"f10"` 等；组合键用 `"ctrl+shift+p"` |
| `PROXY` | `None` | `None` = 直连（会读取环境变量 `HTTPS_PROXY` / 系统代理；直连失败还会自动回退到系统里配置的代理）。需要指定代理时填 `"http://127.0.0.1:端口"` |
| `MONITOR` | `1` | 截图显示器编号（1 = 主屏，2 = 副屏……） |
| `MATCH_CUTOFF` | `85` | 道具名匹配阈值，越高越严格 |
| `OCR_REFINE` | `True` | 对每个文本框裁剪后二次识别，小字（长道具名）准确率更高，速度略慢 |
| `GOLD_FILTER` | `True` | 只把金黄色文字当道具名，过滤玩家名等干扰 |

## 常见问题

- **一直卡在“识别中”或查询失败**：warframe.market 在国内直连常超时。默认会先直连（约 8 秒超时）再回退到系统代理。若你本机代理端口不是系统里配置的那个，请把 `PROXY` 改成实际端口。
- **弹窗被游戏挡住**：置顶窗在“独占全屏”下无法显示，请把游戏改成**无边框窗口**模式，或用第二块屏幕。
- **游戏以管理员运行**：此时脚本也要以管理员运行，否则热键钩子收不到来自游戏的消息。
- **识别不到道具**：确认画面停留在报酬界面、道具名清晰无遮挡；可先用 `--image` 对截图试跑排查。
